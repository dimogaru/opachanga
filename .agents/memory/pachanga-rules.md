---
name: Reglas de O Pachanga
description: Reglas de negocio semanales para convocatorias, equipos, cobros y clasificación.
---

**Regla:** La convocatoria empieza el martes y cierra el lunes siguiente a las 20:00 (Europe/Madrid). Solo se considera apta para jugar con 14–16 jugadores en la lista principal; el admin puede responder, pero no computa como jugador para el draft, cobros, puntos ni clasificación. En el draft empieza el segundo jugador confirmado mejor clasificado; se alterna hasta que queden tres, entonces el primero elige dos seguidos y recibe automáticamente al último. El admin fija el cobro individual; el sobrante tras pagar la pista va al bote. Asistencia da +1, victoria suma +3, empate +1 y derrota no suma extra.

**Why:** el usuario definió estas reglas de negocio para O Pachanga.

**How to apply:** preservar estas condiciones al modificar convocatorias, selección de equipos, finanzas, notificaciones de saldo o clasificación; nunca contar cuentas admin en dinámicas competitivas.
