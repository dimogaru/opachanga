---
name: Reglas de O Pachanga
description: Reglas de negocio semanales para convocatorias, equipos, cobros y clasificación.
---

**Regla:** La convocatoria empieza el martes y cierra el lunes siguiente a las 20:00 (Europe/Madrid). Solo se considera apta para jugar con 14–16 personas en la lista principal. El admin también participa como jugador. En el draft empieza el jugador #2; se alterna hasta que queden tres, entonces el #1 escoge dos seguidos y recibe al último. El admin fija el cobro individual; el sobrante tras pagar la pista va al bote. Asistencia da +1, victoria suma +3, empate +1 y derrota no suma extra.

**Why:** el usuario definió estas reglas de negocio para O Pachanga.

**How to apply:** preservar estas condiciones al modificar convocatorias, selección de equipos, finanzas, notificaciones de saldo o clasificación.
